# Exact-match offline two-person phrase turns (own authored notes)

Tuddy's home screen adds **⇄ Offline gesprek met mijn eigen Kurmanji/Sorani/Pasjtoe-zinnen** alongside, but separate from, the ML Kit two-way translated chat. This gives people a practical way to alternate turns from their **own manually entered** sentences even when no licensed offline ASR/MT model is installed for Kurmanji, Sorani or Pashto.

A participant chooses one of `kmr`, `ckb` or `ps` and the language of their own meaning (`nl` or `en`). They explicitly type a note's original source phrase or its own Dutch/English meaning. Tuddy checks for a **full exact case-insensitive match** in the private on-device phrase deck. There is no stemming, guessing, remote query, ML Kit translation or generated output. When multiple notes share the same author-written meaning, the user **chooses the exact stored pair**. If nothing matches, the screen clearly says there is no authored equivalent and produces no replacement. Only a user-selected pair appears as a conversation turn.

The next turn can automatically reverse input direction, or the user can keep the same direction. The last twelve **deliberately selected** local phrase pairs appear in an ephemeral on-screen conversation and can each be displayed in the existing large phrase presenter. Sorani/Pashto phrases retain right-to-left text direction. **Wis alle beurten** clears the on-screen selection; leaving the screen does the same automatically. There is no transcript store, mic start, clipboard access, network request, downloaded model or permissions change. The existing **Mijn eigen zinnen** editor remains the only route for intentionally saving and editing notes (up to 80).

This is a **bounded, self-authored phrase-memory conversation**, not a claim of arbitrary live offline speech translation. Meanings were entered by the owner and are not independently reviewed; do not rely on them for high-risk situations. P1 [issue #2](https://github.com/Zennay/Tuddy/issues/2) remains open for complete rights-cleared and native-speaker-reviewed offline Kurmanji/Sorani/Pashto ASR+MT. P1 [issue #1](https://github.com/Zennay/Tuddy/issues/1) still requires authorized physical Android 12+ airplane-mode and device/release evidence.
