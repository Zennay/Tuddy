# User-chosen private conversation script export

The separate **Offline gesprek met mijn eigen Kurmanji/Sorani/Pasjtoe-zinnen** screen keeps only the last twelve explicitly chosen *user-written phrase pairs* in memory. By default **nothing is exported**; closing the screen discards those turns. A new optional action **Bewaar uitsluitend deze eigen beurten als tekst…** permits a person to make a portable plain-text script only after an explicit review.

The export includes the order of selected turns, the declared source/target language codes, and the exact self-authored source and meaning. It explicitly labels itself as *not independently verified* and *not automatic translation or speech transcription*. It excludes audio, mic recordings, live captions, other notes, favorites and review dates. The preview shows **the entire exact UTF-8 file** (up to 8 KiB) before the user chooses a destination via Android's Storage Access Framework. When the file picker returns, Tuddy rebuilds the content from the same temporary RAM turns; any changed selection aborts writing. Canceling the preview or Android picker writes nothing.

The chosen Android document provider can sync or externally share a saved file. A copy outside the app is **not deleted** by closing Tuddy or erasing app data. The feature requests no new Android permission and includes no network request itself. It does not generate a translation, claim speaker validation, or provide offline Kurdish/Pashto ASR/MT. [P1 #1](https://github.com/Zennay/Tuddy/issues/1) authorized physical device acceptance and [P1 #2](https://github.com/Zennay/Tuddy/issues/2) rights-cleared/native-speaker-reviewed free-form models remain unresolved.
