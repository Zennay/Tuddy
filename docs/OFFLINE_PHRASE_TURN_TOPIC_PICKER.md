# Offline phrase turns: manual topic and favorites picker

Within Tuddy's **Offline gesprek met mijn eigen Kurmanji/Sorani/Pasjtoe-zinnen**, users can open a temporary **Kies zelf een eigen zin** panel instead of typing the exact original sentence. It uses only the already stored personal phrase deck, filtered by the chosen Kurdish/Pashto source language and Dutch or English own-meaning language.

The picker allows the user to narrow down to one of their **own named topics**, notes without any topic, or one of their **explicitly favorited** notes. It displays the exact stored source text and personal meaning side by side. A tap **Gebruik dit eigen paar als beurt** explicitly adds that original pair to the dialogue's RAM-only list; browsing, scrolling, and filtering never change any saved note, bookmark or topic assignment. The existing option to type an exact phrase remains available.

This makes previously authored phrases usable when the other person cannot type Sorani or Pashto script. A manually selected phrase is not new translation or on-device ASR; no model, cloud call, microphone, automatic suggestion or native-speaker verification is implied. The conversation retains at most twelve ephemeral turns and is cleared on closing; neither source notes nor a chat transcript are exported or persisted.

This is a partial personal phrasebook capability under open [P1 #2](https://github.com/Zennay/Tuddy/issues/2), not satisfaction of the full rights-cleared, native-speaker-reviewed offline Kurmanji/Sorani/Pashto ASR+MT or physical Android acceptance in [P1 #1](https://github.com/Zennay/Tuddy/issues/1).
